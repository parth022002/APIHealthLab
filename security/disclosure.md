# Responsible Disclosure — Draft

API HealthLab is intended for developers testing credentials they own or are explicitly authorized to use. Do not use this project to validate leaked, stolen or third-party credentials without authorization, automate bulk credential checking, or attempt unauthorized access.

If you discover a security issue, report it privately through the project's designated security contact once that contact is configured. Include a concise description, impact, affected component/version and minimal reproduction steps. Do not include live API keys, customer payloads or other people's private data. Allow a reasonable remediation window before public disclosure, coordinated with the maintainer.

**Before public launch:** the project owner must publish a valid contact channel, confirm scope and legal text, and link this draft from the application. This draft is not a substitute for legal review.
