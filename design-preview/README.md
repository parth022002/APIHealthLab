# Motion direction preview

Open `motion-direction.html` directly in a modern browser to view the proposed API HealthLab marketing direction.

This is an **exploratory visual prototype**, not the production web app. It is self-contained (no build step and no external JavaScript libraries), responsive, keyboard accessible, and supports `prefers-reduced-motion`.

Important: the sample diagnostic walkthrough is simulated and makes no network request. It uses no credentials. Do not represent it as live provider testing. Production implementation must use the validated project contracts and actual diagnostic events as specified in `docs/MOTION_AND_INTERACTION.md`.
